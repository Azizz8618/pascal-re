# Компиляция компилятора Паскаль-Монитор и запись в PERSO (том пакета Д-2048)

Рабочий конвейер: реконструированный компилятор (исходник `pascompl.b6`,
написанный на самом Паскале-Мониторе) собирается средствами Монитора-80
(«Дубна», ИАЭ) под эмулятором `dispak`, а результат - объектный модуль
`PASCOMPL` - записывается в персональную библиотеку (PERSO) тома пакета
Д-2048 (рабочая копия 2348; сам том 2048 и его образы не изменяются).
Далее этим компилятором из PERSO собираются и запускаются тестовые
паскаль-программы.

## Окружение

| Что | Где |
|-----|-----|
| Пакетный эмулятор БЭСМ-6 | `dispak` (../dispak, установлен в /usr/local/bin) |
| Мониторная система | Монитор-80 (3.7), МС «Дубна» ИАЭ |
| Пакет Д-2048 | `/usr/local/share/besm6/2048` (8 МБ) и его копия на 29 МБ `~/Yandex.Disk/simh/BESM6/MD/EC5061/2348` |
| Рабочий том конвейера | `~/.besm6/2348` - копия EC5061-образа, создаётся `tools/init-disk-2048.sh` |
| Системная модульная /*PASCAL | диск 2148, зона 440 (`*PERSO:410440`) |
| Исходник компилятора | `pascompl.b6` (task Монитора, 8798 строк) |

Запись ведётся только в рабочую копию тома: все инструменты выставляют
`BESM6_PATH="$HOME/.besm6:/usr/local/share/besm6:<каталог EC5061>"`, так что
том 2348 берётся из `~/.besm6`, а остальные (2148, 2053, ...) - из системных
каталогов на чтение. Исходный образ `MD/EC5061/2348` остаётся неизменным;
`tests/run-tests.sh` сверяет его md5 до и после прогона.

Зонная карта пакета Д-2048 ведётся в
`../re_dispak/re-dispak/rukava.be`, раздел 1.3 (свободное место после зоны
1743). Конвейер занимает на рабочей копии две зоны:

```
2000-2027  *PERSO: /*PASCAL/(PERSO,СЛИT.)  - рабочая библиотека: системная
                                            модульная /*PASCAL + новый PASCOMPL,
                                            баннер "PASCAL COMPILER 15.1 (08.10.26)"
5000-5027  *PERSO: /*PASCAL/(PERSO,ТЕSТ.)  - та же сборка с баннером
                                            "PASCAL COMPILER 99.9 (01.01.70)",
                                            тест происхождения
```

Штатный компилятор печатает `PASCAL COMPILER 15.0 (15.02.82)`; баннеры обеих
копий изменены, поэтому по листингу всегда видно, какой компилятор реально
работает. Буквы в распечатке кодированы TEXT-гомоглифами, поэтому маркеры
выбраны цифровыми.

## Механизм Монитора-80

- `лен LU(ТОМ-wr)^` - карта диспетчера: монтирует том в логическое устройство
  `LU` (октальные 30-67); `-wr` разрешает запись.
- `*PERSO:LUZZZZ` - читает библиотеку с зоны `ZZZZ` устройства `LU` во
  временный каталог задач; `,CONT` дозаписывает в уже загруженный каталог.
- `*TO PERSO:LUZZZZ` - пишет содержимое временного каталога обратно на том;
  монитор печатает `ДЛИНА LIBRARY <NNN> ЗОН` (октально, включая 2 зонные
  каталога).
- `*STAND` - ключевая карта: переводит `*CALL *PASCAL` с предсвязанного
  системного оверлея на модульный путь, при котором используется модуль
  `PASCOMPL` из временного каталога. Без `*STAND` монитор всегда
  запускает штатный компилятор 15.0.
- Разрешение имён: из нескольких загрузок одного имени (`*PERSO:...`,
  затем `*PERSO:...,CONT`) используется последний загруженный модуль.
- `besmtool` принимает номера зон в десятичной системе; мониторные карты -
  в восьмеричной (зона 2000(8) = 1024(10)).

## Алгоритм

### 1. Подготовка рабочего тома

```
tools/init-disk-2048.sh [-f]     # VOL=2348, REF=~/Yandex.Disk/simh/BESM6/MD/EC5061/2348
```

Копирует `~/Yandex.Disk/simh/BESM6/MD/EC5061/2348` (полная копия пакета
Д-2048 на 29 МБ) в `~/.besm6/2348` (`-f` - пересоздать с эталона, сбросив
старые записи PERSO). Переменные `VOL`, `REF`, `SIMHMD` позволяют выбрать
другой том.

### 2. Компиляция компилятора и запись в PERSO

```
tools/perso-build.sh [--mode=merged|compact] [--zone=ZZZZ]
```

Скрипт собирает task Монитора из тела `pascompl.b6` (между картой `*pascal`
и хвостовой `*to perso`, с переводом `{ }` в `_( _)` по образцу `comp.sh`):

```
user 419900 зс5^
лен 41(2148)^                 ; только merged: системная модульная /*PASCAL
лен 40(2348-wr)^              ; том назначения, режим записи
EEB1A3
*name
*call yesmemory               ; расширенная память
*perso:410440                 ; только merged
*pascal                       ; системный компилятор собирает PASCOMPL
... 8798 строк исходника ...
*to perso:40ZZZZ              ; запись результата в PERSO на томе
*end file
``````
ЕКОНЕЦ
```

Параметр `--banner='ТЕКСТ'` подменяет строку баннера компилятора в
пересобираемом исходнике (зона 5000): это единственный способ отличить
наш компилятор от штатного при запуске, поскольку обычный баннер
совпадает с системным (`PASCAL COMPILER 15.0`).

Компиляция выполняется штатным системным компилятором (самостоятельная
пересборка нашим же компилятором возможна через `*STAND` после первой
успешной записи; это следующий этап).

### 3. Проверка записи

```
tools/perso-check.sh --zone=2000 [--zones=030 --dump=pascompl.o]
```

- `besmtool view` читает каталог библиотеки с зоны тома; запись PASCOMPL
  в TEXT-кодировке Дубны видна как `РАSСОМРL...` (греппается по хвосту `МРL`).
- `--dump` выгружает тело модуля в файл: `besmtool dump 2348
  --start=Z+2 --length=<зон-2>` (две первые зоны - каталог, как в
  `format.md` и `../dtran/decomp/pasdms.sh`).

### 4. Использование компилятора из PERSO

```
tools/perso-run.sh tests/cases/writeln77.pas --zone=2000
```

```
лен 40(2348)^
*perso:402000                 ; merged: всё нужное в одной библиотеке
*stand                        ; брать PASCOMPL из временного каталога
*call *pascal
... текст программы ...
*execute
```

Режим `compact` (`--mode=compact`) пишет только модуль `PASCOMPL` без
системной обвязки; он удобен для временных томов, тогда загрузка идёт двумя
картами: `*perso:410440` затем `*perso:40ZZZZ,cont`. Постоянных зон на
рабочем томе под него не отводится.

## Тесты

`tests/run-tests.sh` - полный прогон (пересоздаёт рабочую копию тома и обе
библиотеки, занимает несколько минут, 10 проверок):

1. Запись рабочей (зона 2000, баннер `15.1 (08.10.26)`) и тестовой (зона
   5000, баннер `99.9 (01.01.70)`) библиотек и наличие `PASCOMPL` в
   каталоге.
2. Функциональные тесты компиляции и выполнения через рабочую библиотеку:
   `writeln77`, `sieve` (решето, из `../dispak/tests/pascal-monitor`),
   `forloop` (из AGENTS.md) - сверка с `tests/golden/`, маскировка дат в
   заголовках страниц, `#` как wildcard (семантика `run-test.py` из dispak).
3. Баннеры: распечатка компиляции из зоны 2000 содержит `15.1 (08.10.26)`,
   из зоны 5000 - `99.9 (01.01.70)`, и ни там ни там нет штатного
   `15.0 (15.02.82)`, значит работает компилятор из PERSO, а не оверлей.
4. `perso-check.sh` проверяет читаемость обоих каталогов.
5. Защита эталона: md5 образа `MD/EC5061/2348` до и после прогона совпадают.

`RECORD=1 tests/run-tests.sh` перегенерирует золотые файлы.

## Связанные проекты

- `../dispak` - эмулятор, `besmtool`, тесты `tests/pascal-monitor`,
  `fortran-dubna`, `librefer-2048` (карты `лен`/`*perso` на 2048).
- `../monitor80-re` - реконструкция Монитора-80; модуль `LIBDRUM` (*PERSO),
  `%PASCAL`, `GIVTRAN` (режимы трансляции), `inputcal` (WORKVOL=80).
- `../re_dispak/re-dispak` - ОС ДИСПАК и справочник зон `rukava.be`
  (`../re-dispak` - более старый снимок того же дерева)
  (раздел 1.3 описывает том 2048, включая записи PERSO этого конвейера).
- `../simh/BESM6` - аппаратный эмулятор; откуда берётся эталон:
  `BESM6/MD/EC5061/2348` (копия пакета Д-2048 на 29 МБ). Конвейер читает её
  и пишет только в `~/.besm6/2348`; образы `MD/2048` и `MD/EC5061/*` этим
  конвейером не изменяются.
- `../dtran` - дизассемблер/сверка объектов; `pasdms.sh` - прообраз
  записи в PERSO и извлечения модулей.
- `~/besm-operator` - операторские сценарии Дубны, примеры `*LIBRARY`/`*PERSO`.
